1 1. Aim and modelling strategy

File 1 explored associations between movie duration, audience ratings, film classification, genres, release year and vote counts. This document applies the regression methods from the supervised-learning lectures to two different target types:

  1. Multiple linear regression: explain variation in a continuous outcome, the average audience rating.
  2. Binary logistic regression: estimate the probability of a categorical outcome, the dataset’s Short classification.

The choice of model follows the target: linear regression models a continuous response, whereas logistic regression models the probability of a binary response. The models describe adjusted associations and predictive performance; neither establishes causation.

The Short variable is an independent dataset classification, not a fixed runtime cutoff. Runtime is therefore a possible predictor of this label, not its definition. This report includes the lecture material directly relevant to these regression tasks. Other supervised-learning topics such as self-supervised pretraining, PCA workflows and neural-network interpretation are outside the scope of this particular assignment.

All required analysis variables are complete in the retained dataset. Genre indicators are kept separately because a movie can belong to more than one genre. length_60 expresses runtime in hours for the linear model; length_10 expresses it in ten-minute units for easier logistic odds-ratio interpretation. log10_votes is a log-transformed vote count with a +1 offset to retain zero-vote observations; a one-unit increase is approximately a ten-fold increase for non-zero counts.

The 80/20 split is stratified by Short so both classes are represented in the training and test sets. The test set is held aside for final evaluation and is not used to fit or choose the models. Preprocessing that requires an estimated value (centering year) is based on the training data and then applied unchanged to the test data. This avoids a basic form of data leakage: allowing information from the test set to influence model fitting or preprocessing.

2.0.1 R formula and variable coding

The R model formula follows the syntax shown in the R practicals: the response is on the left of ~, and predictors are on the right. The + operator adds predictors; * includes both main effects and their interaction. We use an explicit predictor list rather than . so that movie_id and any unintended columns cannot enter the model. film_type is a factor with Other film as the reference level, as categorical predictors should be encoded as factors when their numeric codes are only labels. The 0/1 genre indicators remain numeric binary predictors, and short_binary remains a numeric 0/1 response for the binomial GLM.

The analysis uses readable object names, pipes for data preparation, a reusable clean_table() helper, comments explaining non-obvious choices, and stopifnot() to fail early if required variables are absent. These follow the R refresher’s KISS, DRY, abstraction and input-checking guidelines. The regression models are ordinary R model objects; summary(), anova(), confint() and predict() are used to inspect and apply their standard methods.

3 3. Multiple linear regression: explaining audience ratings

3.1 3.1 Model idea and sequential specification

The response, rating, is a numerical score from 1 to 10, so linear regression is a suitable starting point. With multiple predictors, the model estimates the outcome as a linear combination of those predictors. A coefficient describes the expected change in rating for a one-unit increase in that predictor, holding the other included predictors constant.

For ordinary least-squares regression, the fitted coefficients minimise the sum of squared residuals (SSE). A residual is the observed rating minus its fitted rating. Squaring prevents positive and negative errors from cancelling and gives larger errors more weight.

We fit three nested models on the training set:

  • Model 1: runtime only; an unadjusted reference relationship.
  • Model 2: adds release year, log-transformed vote count, film classification and the six genre indicators.
  • Model 3: adds an interaction between runtime and film classification to test whether the runtime-rating slope differs between short films and other films.

The reference category is Other film. In Model 3, the length_60 coefficient is the runtime slope for other films; the interaction coefficient is the additional slope for short films.

linear_model_1 <- lm(
  rating ~ length_60,
  data = regression_train
)

linear_model_2 <- lm(
  rating ~ length_60 + year_c + log10_votes + film_type +
    Action + Animation + Comedy + Documentary + Drama + Romance,
  data = regression_train
)

linear_model_3 <- lm(
  rating ~ length_60 * film_type + year_c + log10_votes +

3.3 3.3 Check assumptions and collinearity

The diagnostic plots help assess whether a linear model is a reasonable summary. A curved residual pattern can indicate non-linearity; a changing residual spread can indicate heteroscedasticity; and departures in the Q-Q plot indicate non-normal residuals. Extreme outliers can also influence least-squares estimates. Independence is primarily a study-design assumption and cannot be established from these two plots. With a large dataset, practical effect sizes and plots should be considered alongside p-values.

The coefficient estimates should therefore be interpreted conditionally and with this limitation in mind.

3.4 3.4 Cross-validation and held-out prediction

Training fit alone does not show whether a model generalises. Cross-validation repeatedly fits the model on part of the training data and evaluates it on the omitted fold. We use ten-fold cross-validation to estimate variation in predictive error, then evaluate the final fitted model once on the untouched test set. For cross-validation, we use the uncentred release year (year) rather than year_c. Because the model includes an intercept, these formulations are algebraically equivalent, while using the original year avoids estimating a centring constant from observations that may be part of a validation fold.

# The R practical demonstrates 10-fold CV with caret::train().

4 4. Logistic regression: modelling short-film classification

4.1 4.1 Binary outcome, probabilities, odds and log odds

The response is short_binary: 1 indicates the dataset’s short-film classification and 0 indicates another film. Unlike linear regression, logistic regression does not fit a straight line directly to a 0/1 response, because a straight line can produce values below 0 or above 1. Logistic regression models the log odds and transforms the result into a probability between 0 and 1.

For a probability \(p\):

  • Odds are \(p/(1-p)\).
  • Log odds are \(\log[p/(1-p)]\), which can take any real value.
  • The logistic model is \(\log[p/(1-p)] = \beta_0 + \beta_1X_1 + \cdots + \beta_pX_p\).
  • The corresponding probability is \(p = 1/[1+\exp(-z)]\), where \(z\) is the linear predictor.

The logistic model is fitted by maximum likelihood. Equivalently, the fitting procedure minimises the negative log-likelihood (often called log loss), rather than the sum of squared residuals used by ordinary least squares.

Exponentiating a coefficient gives an odds ratio. An odds ratio is not a probability difference or a risk ratio. For example, an odds ratio below 1 means the odds decrease as the predictor increases, holding other variables constant.

4.3 4.3 Interpret odds ratios

The coefficient is a change in log odds. Exponentiating it gives the odds ratio for a one-unit increase in the predictor. For runtime, one unit is ten minutes; for log10_votes, one unit is approximately a ten-fold increase in votes. Confidence intervals quantify uncertainty in the estimated odds ratios.

Raw coefficient magnitudes should not be used on their own to rank predictor importance: predictors are measured in different units and ranges. Interpret the effect using the variable’s scale, plausible changes, uncertainty and the other predictors in the model.

4.4 4.4 Evaluate classification on the held-out test set

The model returns a probability for each test movie. A threshold of 0.50 is used as a conventional starting point. The threshold is a decision rule, not a biological boundary; raising or lowering it changes the trade-off between sensitivity and specificity. We do not tune the threshold on the final test set.

The confusion matrix separates true positives (TP), false positives (FP), false negatives (FN) and true negatives (TN). Accuracy is (TP + TN) / (TP + FP + FN + TN). Sensitivity is TP / (TP + FN), while specificity is TN / (TN + FP). The ROC curve plots sensitivity against the false-positive rate, 1 - specificity, over classification thresholds. Accuracy is reported alongside sensitivity and specificity because accuracy alone can be misleading when classes are imbalanced. ROC-AUC summarises discrimination across possible thresholds; it does not measure probability calibration or select the final decision threshold.

# Build ROC coordinates by accumulating true and false positives
# at each distinct predicted probability (ties remain together).
roc_core <- tibble(
  probability = test_probability,
  actual = truth
) %>%
  group_by(probability) %>%
  summarise(
    TP_added = sum(actual == 1),
    FP_added = sum(actual == 0),
    .groups = "drop"
  ) %>%
  arrange(desc(probability)) %>%
  mutate(
    TP = cumsum(TP_added),
    FP = cumsum(FP_added),
    TPR = TP / n_positive,
    FPR = FP / n_negative
  ) %>%
  transmute(FPR, TPR)

5 5. Model selection, regularisation and limitations

The sequential comparisons show whether adding predictor groups improves the model. AIC and nested-model tests should be read alongside coefficient size, uncertainty, diagnostic plots and the study question; a single statistic should not determine the model automatically.

The lectures also introduce regularisation as a way to reduce overfitting when models contain many or strongly correlated predictors. Ridge regression (L2 penalty) shrinks coefficients, while LASSO (L1 penalty) can shrink some coefficients to zero and perform feature selection. We do not fit a penalised model here because the assignment uses a relatively small, pre-specified set of predictors and focuses on interpreting multiple and logistic regression. If the predictor set were much larger, or coefficient instability from collinearity were substantial, ridge or LASSO could be considered and the penalty strength (\(\lambda\)) selected using cross-validation on the training data only.

Other limitations are important. The observations are movies from a historical dataset ending in 2005. Vote count is a proxy for audience engagement and may be related to rating and visibility. Genre indicators overlap, so their coefficients are conditional on the other included genres. Budget and MPAA are omitted because of missingness. Unmeasured factors such as marketing, distribution, production context and audience composition may influence ratings and votes. The very high logistic classification performance and any numerical 0/1 probability warnings require particular caution: the model may be exploiting a very strong relationship between runtime and the dataset’s Short label. This does not show that runtime defines the label.

Finally, predictive performance and interpretability are different goals. Linear and logistic regression are relatively interpretable compared with complex black-box models, but their coefficients still describe conditional associations, not mechanisms or causal effects. Test-set performance should be interpreted as generalisation to movies drawn from a similar dataset, not automatically to contemporary films.
